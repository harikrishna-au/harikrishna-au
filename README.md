## Featured project

### [Harry The Blaze](https://github.com/harikrishna-au/gbar_made_easy) · [harrytheblaze.site](https://www.harrytheblaze.site)

Cognitive games and communication rounds modelled on company placement assessments, plus paid 20-minute 1:1 calls with recently placed seniors. **6,000+ registered users.**

- Paid slot booking that stays correct under concurrency: a Postgres exclusion constraint prevents overlapping bookings, with handling for expired holds and late payments.
- Razorpay payments and webhooks, Clerk auth, Supabase row-level security and Deno edge functions.
- AI features: job-description parsing, resume parsing, an AI interview, and communication scoring.
- Stack: React, TypeScript, Vite, Tailwind, Supabase, FastAPI on AWS Lambda.
